# Seacurity

Aplikasi web edukasi keamanan siber bertema samudra digital.

## Cara Upload ke GitHub
1. Ekstrak file ZIP ini ke sebuah folder.
2. Buat repository baru di GitHub.
3. Upload `index.html`, `seacurity.html`, dan `README.md` ke repository tersebut.
4. Aktifkan **GitHub Pages** pada menu *Settings > Pages* (pilih branch `main` dan folder `/ (root)`).
